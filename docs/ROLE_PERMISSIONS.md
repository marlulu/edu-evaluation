# 系统角色权限文档

本文档描述人工智能课程作业评价系统中各角色的身份权限配置。

## 角色概览

系统定义了四种用户角色：

| 角色 | 英文标识 | 说明 |
|------|----------|------|
| 管理员 | `ADMIN` | 系统最高权限，负责用户管理、系统配置和运维 |
| 教师 | `TEACHER` | 课程管理者，负责作业创建、评价配置和结果审核 |
| 助教 | `ASSISTANT` | 教学辅助，协助评价和结果查看 |
| 学生 | `STUDENT` | 作业提交者，查看自己的作业和评价反馈 |

## 模块访问权限

各角色可访问的系统模块如下：

| 模块 | 管理员 | 教师 | 助教 | 学生 |
|------|:------:|:----:|:----:|:----:|
| 工作台 (dashboard) | ✅ | ✅ | ✅ | ✅ |
| 作业管理 (assignment) | ✅ | ✅ | ❌ | ❌ |
| 智能评价 (evaluation) | ✅ | ✅ | ✅ | ❌ |
| 结果反馈 (results) | ✅ | ✅ | ✅ | ❌ |
| 系统配置 (system) | ✅ | ❌ | ❌ | ❌ |
| 我的反馈 (student) | ❌ | ❌ | ❌ | ✅ |

## 功能权限列表

系统定义了以下功能权限：

| 权限标识 | 权限名称 | 说明 |
|----------|----------|------|
| `USER_MANAGE` | 用户管理 | 创建、编辑、停用用户账号 |
| `PERMISSION_GRANT` | 权限调整 | 分配和修改用户角色与权限 |
| `RUBRIC_MANAGE` | 评价模板管理 | 创建、编辑、复制评价指标体系 |
| `MODEL_MANAGE` | 模型配置管理 | 配置和测试 AI 模型网关 |
| `AUDIT_VIEW` | 审计日志查看 | 查看系统操作日志 |
| `DATA_EXPORT` | 数据导出 | 导出审计日志、评价结果等数据 |
| `BACKUP_RESTORE` | 备份恢复 | 创建备份和执行恢复操作 |
| `RESULT_REVIEW` | 结果复核 | 审核和调整评价结果 |

## 默认角色权限配置

### 管理员 (ADMIN)

**默认权限**：
- `USER_MANAGE` - 用户管理
- `RUBRIC_MANAGE` - 评价模板管理
- `AUDIT_VIEW` - 审计日志查看
- `BACKUP_RESTORE` - 备份恢复

**数据范围**：`ALL`（所有课程和班级）

**可执行操作**：
- 用户管理：新增、编辑、停用用户
- 角色分配：为用户分配角色和权限
- 评价模板：创建、编辑、复制、启用/停用模板
- 模型配置：新增、编辑、测试 AI 模型配置
- 审计日志：查看、检索、导出日志
- 备份恢复：创建备份、执行恢复

### 教师 (TEACHER)

**默认权限**：
- `ASSIGNMENT_MANAGE` - 作业管理
- `RUBRIC_MANAGE` - 评价模板管理
- `RESULT_REVIEW` - 结果复核

**数据范围**：所教授的课程（如：`人工智能概论`）

**可执行操作**：
- 作业管理：创建、编辑、发布作业
- 评价配置：选择和配置评价模板
- 智能评价：创建评价任务、查看评价进度
- 结果审核：查看评价结果、人工复核调整
- 结果导出：导出评价报告

### 助教 (ASSISTANT)

**默认权限**：
- 无额外功能权限（通过模块访问控制）

**数据范围**：所协助的课程

**可执行操作**：
- 智能评价：查看评价任务、协助评价
- 结果查看：查看评价结果和报告
- 结果导出：导出评价报告

### 学生 (STUDENT)

**默认权限**：
- 无额外功能权限

**数据范围**：仅限个人数据

**可执行操作**：
- 查看作业：查看教师发布的作业要求
- 提交作业：上传作业文件
- 查看反馈：查看自己的评价结果和反馈
- 查看历史：查看历史作业和评价记录

## 权限配置示例

### 创建教师权限用户

```json
{
  "username": "teacher02",
  "displayName": "张老师",
  "email": "zhang@example.edu",
  "roles": ["TEACHER"],
  "permissions": ["ASSIGNMENT_MANAGE", "RUBRIC_MANAGE", "RESULT_REVIEW"],
  "dataScopes": ["人工智能概论", "机器学习基础"],
  "status": "ACTIVE"
}
```

### 创建多角色用户

```json
{
  "username": "senior-assistant",
  "displayName": "高级助教",
  "email": "assistant@example.edu",
  "roles": ["ASSISTANT", "TEACHER"],
  "permissions": ["RUBRIC_MANAGE", "RESULT_REVIEW"],
  "dataScopes": ["人工智能概论"],
  "status": "ACTIVE"
}
```

## 权限验证流程

1. 用户登录系统
2. 系统根据用户角色加载可访问模块列表
3. 前端根据模块权限显示/隐藏功能入口
4. 后端 API 验证用户权限和数据范围
5. 敏感操作（如用户管理、备份恢复）需要管理员权限

## 安全说明

- 当前版本为演示版本，使用预置账号登录
- 生产环境应接入真实的认证服务（如 OAuth2、LDAP）
- 敏感操作应记录审计日志
- API Key 等敏感信息应加密存储
- 数据权限应在后端进行强制验证
